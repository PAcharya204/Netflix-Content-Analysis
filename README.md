# Netflix Content Analysis using Python & Power BI

## About the Project

This project demonstrates an end-to-end data analytics workflow using Python and Power BI.
It includes data cleaning, exploratory data analysis (EDA), and the creation of an interactive dashboard to gain insights from Netflix's content catalog.

## Dataset

**Dataset:** Netflix Titles Dataset

**Source:** Kaggle

## Data Cleaning & Preprocessing

Before creating the dashboard, I cleaned and prepared the dataset by:

- Handling missing values
- Converting date columns to the correct format
- Cleaning text columns
- Creating separate tables for Countries, Genres, Directors, and Actors for better analysis in Power BI
- Preparing the cleaned dataset for visualization

# Key Insights

Some interesting observations from the analysis:

- Movies make up a larger share of Netflix content than TV Shows.
- The United States has the highest number of titles available on Netflix.
- Drama and International Movies are among the most common genres.
- Most Netflix movies have a duration of around 90–100 minutes.
- Most TV Shows have only one or two seasons.
- Netflix's content library has grown rapidly in recent years.
